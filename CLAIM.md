# Claim notes

One line per claim, in this format:

`file(s) | bot | start time | intent`

- Start time should include a timezone (for example `2026-11-11 15:04 UTC` or `2026-11-11 10:04 America/New_York`).
- Add the claim line before you start editing those files.
- Remove the claim line in the same push that finishes the work.
- If a claim is more than a few hours old, ask the bot who wrote it before taking the file over. Do not delete a stale claim or start editing the file as if it were free.
